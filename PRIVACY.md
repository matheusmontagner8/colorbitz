# Política de privacidade — Colorbitz

*Última atualização: 13 de novembro de 2026*

[English version below](#privacy-policy--colorbitz)

O Colorbitz é um jogo de quebra-cabeça para Android. Esta política explica quais
dados o jogo usa.

## Dados coletados

**Nenhum.** O Colorbitz não coleta, não envia e não compartilha dados pessoais.

- O jogo **não acessa a internet** e não tem contas, login ou cadastro.
- O progresso (estrelas, poderes, conquistas, sequência diária) e as opções
  (som, música, vibração, efeitos e idioma) ficam salvos **no seu aparelho**,
  no armazenamento interno do próprio app. Se o backup do Android estiver ligado
  no seu celular, o próprio Android pode copiar esse arquivo para o backup da sua
  conta Google (para restaurar o progresso num celular novo); o jogo não tem
  acesso a esse backup. Desinstalar o jogo apaga os dados do aparelho; também é
  possível apagá-los em *Opções → Apagar progresso*.
- O botão *Opções → Sobre → Relatar problema* abre o GitHub no navegador com um
  formulário já preenchido com a versão do jogo, a versão do Android e o modelo
  do aparelho. Nada é enviado se você não enviar o formulário, e você pode
  apagar ou mudar esses dados antes.
- A fase diária é calculada a partir da data do aparelho, sem consultar nenhum
  servidor.
- O jogo usa apenas a permissão de **vibração**, que pode ser desligada nas opções.

## Crianças

O jogo não coleta dados de ninguém, inclusive de crianças.

## Mudanças nesta política

Se uma versão futura passar a usar algum serviço que trate dados (por exemplo,
anúncios), esta política será atualizada **antes** dessa versão ser publicada,
explicando quais dados são usados e como recusar.

## Contato

Dúvidas sobre privacidade: abra uma *issue* em
<https://github.com/matheusmontagner8/colorbitz/issues>.

# Privacy policy — Colorbitz

*Last updated: November 13, 2026*

Colorbitz is a puzzle game for Android. This policy explains what data the game uses.

## Data collected

**None.** Colorbitz does not collect, send or share any personal data.

- The game **does not access the internet** and has no accounts, login or sign-up.
- Your progress (stars, powers, achievements, daily streak) and settings (sound,
  music, vibration, effects and language) are stored **on your device**, in the
  app's private storage. If Android backup is turned on on your phone, Android
  itself may copy this file to your Google account backup (to restore your progress
  on a new phone); the game has no access to that backup. Uninstalling the game
  deletes the data on the device; you can also delete it in *Options → Reset progress*.
- The *Options → About → Report a problem* button opens GitHub in your browser with
  a form pre-filled with the game version, the Android version and the device model.
  Nothing is sent unless you submit the form, and you can delete or change this data
  before submitting.
- The daily level is computed from the device's date, without contacting any server.
- The game only uses the **vibration** permission, which can be turned off in the options.

## Children

The game does not collect data from anyone, including children.

## Changes to this policy

If a future version starts using a service that handles data (for example, ads),
this policy will be updated **before** that version is released, explaining which
data is used and how to opt out.

## Contact

Privacy questions: open an issue at
<https://github.com/matheusmontagner8/colorbitz/issues>.
